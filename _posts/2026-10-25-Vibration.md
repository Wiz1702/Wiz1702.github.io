This time, I made my Arduino communicate using Morse code through vibrations!

Vibe It!

For this assignment, I programmed my LilyPad USB Plus to use a Vibe Board to send two different Morse code messages. When the alligator clip circuit is open, the Vibe Board vibrates my name, WISDOM. When the circuit is closed, it sends SOS.

I created separate functions for the Morse code letters and used different vibration lengths for dots and dashes.

Tips

My advice to my past self would be to test the dots and dashes separately before combining them into words. Also, use the Serial Monitor to check whether the Arduino is detecting the circuit correctly!
